# 我的课程表

一个面向 Android 手机的个人课程表应用，适用于邢台学院学生。应用通过 WebView 登录学校教务系统，将当前课表同步到本地，也支持手动添加课程、查看教学周和设置上课提醒。

## 功能简介

- 从邢台学院教务系统同步个人课表
- 以周视图表格展示课程安排
- 支持周次切换和当前周定位
- 支持手动添加、查看和删除课程
- 支持课程上课提醒，可单独开启或关闭
- 支持浅色模式和夜间模式
- 支持在设置中查看软件基本信息
- 课程和学期设置保存在设备本地

## 使用方法

### 直接安装 APK

从RELEASES下载安装包后，发送至手机，安装完成后，打开“我的课程表”即可使用。首次使用建议先完成学期设置，再同步课表。

### 同步教务课表

1. 打开应用，进入“设置”。
2. 在“学期设置”中填写本学期第一周周一日期，例如 `2026-09-07`，点击“保存日期”。
3. 点击“登录并同步课表”。
4. 在学校统一身份认证页面完成登录。
5. 进入智慧校园或教务系统，打开学生个人课表页面。
6. 点击“同步当前页面”。
7. 返回“课表”页面查看同步结果。

如果提示未读取到课程，请确认当前 WebView 页面已经打开学生课表，而不是教务系统首页或其他页面。

### 手动添加课程

进入“课表”页面，点击右下角的“+”，填写课程名称、星期和节次。教师和教室信息可以选填。

### 设置夜间模式

进入“设置”，打开“夜间模式”开关。设置会自动保存在本地，重新启动应用后仍然有效。

## 从源码构建

使用 Android Studio 打开项目目录，等待 Gradle 同步完成后，选择 `app` 模块运行或构建。

调试版 APK 默认输出到：

```text
app/build/outputs/apk/debug/app-debug.apk
```

生成正式版 APK 时，请使用 Android Studio 的 `Build > Generate Signed App Bundle or APK`，选择 `release` 构建类型并使用自己的签名文件。

## 数据与隐私

- 登录操作在学校官方页面中完成。
- 本项目不主动上传或收集账号、密码和课程数据。
- 课程、学期和提醒设置保存在应用本地数据库中。
- 请妥善保管设备、签名文件以及教务系统登录信息。
